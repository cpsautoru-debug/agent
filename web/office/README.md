# АвтоСклад63 — онлайн-офис

Первая версия: адаптивная навигация по отделам, каталог 9 ролей, фильтр и поиск команды, карточки обязанностей, процесс заказа и ссылки на рабочую Google Таблицу.

Реальные заказы, оплаты и складские строки не включены в исходники. Автономных агентов подключено 0. Сайт не запрашивает и не хранит токены Google; доступ к таблице проверяет сам Google при переходе по ссылке. Цифры структуры офиса — конфигурация ролей, не телеметрия.

Хостинг Sites, доступ владельца. Манифест `.openai/hosting.json`; статические файлы `dist/`. Код также хранится в основном GitHub-репозитории. Сайт не размещается на GitHub Pages.

Для локального просмотра использовать любой статический HTTP-сервер с корнем в этой папке. Сборка и установка зависимостей не требуются.

Следующий этап: авторизованное чтение Google Таблиц и диспетчер с журналом запусков. Пока данные открываются в самой таблице; сайт не выполняет отправки клиентам и списания.

Обновление 19.10.2026: 12 ролей; добавлен ВК-агент для vk.ru/autosklad63, контент-студия (#studio) с бесплатным дизайнером PNG и локальной очередью брифов, раздел запуска производства (#production). Студия работает в браузере, без фонового исполнителя и API ВК. Фото не отправляются на сервер. Брифы хранятся на устройстве. MAX-приём и распределение заявок отражены в карточке менеджера продаж. Подробности — docs/vk-design-workflow.md.
