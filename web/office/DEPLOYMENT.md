# Размещение офиса

Исходники первой версии хранятся в этой папке GitHub. Веб-страница работает на хостинге Sites с доступом владельца; GitHub Pages не используется. Рабочие заказы и финансовые данные не включены в сайт.

Эта папка — копия статических исходников сайта: `index.html`, `app.js`, `style.css`. Для другого статического хостинга они работают без сборки. Авторизацию должен обеспечивать выбранный хостинг: надпись «Доступ владельца» сама по себе не защищает страницу.

Локальный исходный проект Sites: `apps/online-office` (игнорируется основным Git, имеет собственный управляемый репозиторий Sites). При изменениях синхронизировать статические файлы этой папки и проекта Sites до публикации.

Нет автоматической синхронизации с Sheets и телеметрии процессов. Девять ролей настроено, постоянно подключённых агентов — ноль. Не заменять эти показатели вымышленной активностью.
