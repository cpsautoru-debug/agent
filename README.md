# Рабочее пространство ИИ-команды

Исходники браузерного онлайн-офиса: [web/office](web/office/DEPLOYMENT.md).

Открыть офис: https://autosklad63-office.sunsetbear9.chatgpt.site (вход владельца через ChatGPT).

Единый центр управления агентами Антона. Подготовлены структура отделов, инструкции ролей, шаблоны задач и код существующего Instagram-агента.

## Отделы

| Отдел | Роли | Результат |
|---|---|---|
| Управление | Координатор, менеджер проектов | Приоритеты, задачи, контроль сроков |
| Маркетинг | Маркетолог | Контент и анализ каналов |
| Продажи | Менеджер продаж, Instagram-агент, агент ВБ, агент Озон | Обращения, отзывы, акции и передача заказов; API маркетплейсов ожидают подключения |
| Дизайн | Дизайнер | Макеты, визуалы, материалы для публикаций |
| Финансы | Финансовый управляющий | Расчёты маржи, бюджет, денежный план |
| Склад | Кладовщик | Остатки, резервы, дефицит, заявки на закупку |
| Разработка | Разработчик | Приложения, интеграции, проверки |

## Начать работу

Рабочая Google Таблица уже создана. Ссылку, ответственность ролей и порядок следующего цикла см. в [подключённом пространстве](docs/connected-workspace.md).

1. Заполнить [данные компании](knowledge/company.md) и подтверждённые условия продаж.
2. Выбрать роль в папке agents. Передать исполнителю её инструкцию, AGENTS.md и конкретную задачу.
3. Задачи вести по [единому процессу](docs/workflow.md). Пока GitHub не подключён, использовать [локальную очередь](tasks/backlog.md).
4. Код Instagram-агента расположен в apps/instagram-agent; запуск и подключения описаны в его README.
5. Разместить это пространство в закрытом репозитории по [инструкции](docs/github.md).

## Что работает сейчас

Инструкции ролей — готовые задания для ИИ, но сами по себе они не запускают автономных сотрудников. Существующий Instagram-сервис перенесён без рабочих секретов и истории клиентов; его подключение к Meta и постоянный сервер ещё требуют настройки. Финансы, склад, CRM и другие каналы пока не подключены. Автономный общий диспетчер пока не реализован.

GitHub хранит код, инструкции и задачи. Рабочие сообщения, персональные данные, реальные остатки и финансовые операции должны поступать из подключённых систем. GitHub Actions здесь проверяет код Instagram-сервиса, но не запускает отделы.
