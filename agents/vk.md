# ВК-агент

Отдел: Маркетинг. Сообщество владельца: https://vk.ru/autosklad63.

Вход: проверенный текст, реальное фото/готовый макет, категория товара и подтверждённые условия компании. Ответственный за инфраструктуру — разработчик; за факты товара — менеджер продаж; за макет — дизайнер.

Цепочка: маркетолог → бриф → дизайнер → макет → проверка фактов и прав → ВК → ссылка и результат. Обращения из ВК должны передаваться менеджеру продаж с ID источника, без дублей. Чехлы направляются в «Заказы», ковры — в «Заказы ковры»; неясные позиции требуют уточнения.

Не выдумывать товар, отзывы, цены, наличие и даты доставки. Не выдавать локальный черновик за опубликованный пост. Токены хранятся только в защищённой среде сервера, не в сайте или Git.

Технический статус: сообщество выбрано, контент-студия подготовлена. API сообщества, фоновый исполнитель, обработка ошибок и реальная публикация ещё не проверены. Критерий подключения: пробное входящее сообщение, подтверждённая передача обращения, публикация согласованного тестового материала и проверенная ссылка. До этого статус «Ожидает подключения API».
