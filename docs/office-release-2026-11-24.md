## Нерешённые блокеры — без повторных исследований
1. WB: серверная синхронизация 35 цен отвечает `write/database_operation_failed`. Прямая запись через подключённый Cloudflare REST API также отклонена с кодом 7500 `You do not have permission to perform this operation` (24.11.2026); существующая таблица `wb_profit_unit_costs` имеет единственную предварительную запись по «веста №2». Не менять подтверждённый октябрьский P&L. В ветке есть атомарная двухоперационная D1 batch-запись; требуется результат нового успешного POST под владельцем или исходная серверная причина отказа. Не делать повторных попыток без исправления причины.
2. Яндекс: подтверждено одно ООО для двух магазинов. В API опубликован выбор отчёта для каждого `campaignId` отдельно или двух магазинов вместе; совместный отчёт нельзя снова суммировать с магазинными. Отчёт по заказам распаковывается. Ещё нет документированной операции классификации полей, проверки услуг и возвратов, количества проданных единиц по offer и полной себестоимости; P&L отложен. Не включать в суммарную прибыль платежи или суммы разных листов без сверки.
3. Производство: D1 содержит результаты обхода, но состояние `scanning` не равно завершённому обходу и не является подтверждением актуальных остатков двух складов.
4. Финальный результат бизнеса неизвестен из-за Яндекс, Авито, офлайна, расходов, налогов по разным юрлицам и банковской сверки.
