## Следующий технологический gate — строго отдельный preview

1. **Инфраструктура (ответственный: разработчик).** Через Cloudflare Pages проверить, связан ли проект `autosklad63-office-staging` с GitHub, включены ли preview-ветки и корректна ли папка статических файлов `web/office` и Functions `functions/`. **Не** менять текущие Worker, Cron, секреты или production D1. Настройки из исходного репозитория не доказывают конфигурацию Cloudflare.
2. **Развёртывание (ответственный: разработчик, только после разрешения для конкретной среды).** Опубликовать commit PR №22 в *отдельном* preview-проекте/ветке, не в `autosklad63-office-staging.pages.dev` как production-алиас. Проверить, что Pages Functions публикуются вместе со статикой и preview использует корректные, отдельно разрешённые привязки.
3. **Анонимный smoke (ответственный: разработчик).** Выполнить из рабочей среды Node 22:
   ```bash
   node scripts/ms-preview-smoke.mjs https://<verified-preview-alias>.autosklad63-office-staging.pages.dev/
   ```
   Подставлять URL **из реальной карточки deployment**, а не угадывать. Скрипт отклоняет основной staging-адрес, проверяет HTML, оба JS-модуля и `401 JSON owner_session_required` на защищённом GET без cookie. Никакого секретного токена в команду не передавать.
4. **Owner probe (ответственный: владелец в авторизованной сессии, один запуск).** На preview открыть `#production`, нажать «Оценить объём API». Должно быть ровно два последовательных запроса `limit=1`. Зафиксировать в приватном рабочем отчёте только числа `totalTaskDocuments`, `totalProductionStages` и признаки `sampleStageHasTaskReference`, `sampleStageHasRowReference`. Ни UUID, ни токен, ни содержимое строк не переносить в GitHub.
5. **Контроль безопасности (ответственный: разработчик).** Проверить запрет для гостя, отсутствие новых записей, отсутствие Cron и отсутствие изменений статистики финансов. Наличие `200` на статике не подтверждает работу API. При ошибке остановить процесс без повторного массового опроса.

### Где остановиться

Если preview-ветки не создаются из GitHub — выяснить, включена ли Git integration, или проект создан через Direct Upload. Не переключать тип Cloudflare Pages-проекта наугад. Если endpoint API отдаёт HTML или 503 — не выполнять owner probe и не интерпретировать данные как ноль.
