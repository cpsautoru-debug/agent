# Работа с задачами

Статусы: Входящие → Готово к работе → В работе → На проверке → Завершено. Для ожидания данных — Заблокировано с причиной.

Одна задача — один проверяемый результат. Поля: отдел, роль, приоритет, срок при наличии, входные данные, результат, критерий приёмки, зависимости, ссылки на материалы. В GitHub это Issue, связанный с изменениями через Pull Request.

Пример цепочки: маркетолог готовит тему → дизайнер создаёт материалы → владелец утверждает публикацию → Instagram-агент обрабатывает обращения в разрешённом режиме → менеджер продаж уточняет заказ → кладовщик проверяет наличие → финансовый управляющий считает маржу → владелец подтверждает нестандартные условия.

Координатор управляет очередью, а готовность определяет по результатам и проверкам. При отсутствии подключений этап остаётся ручным. Финансовые расчёты и остатки должны содержать источник и дату актуальности.
