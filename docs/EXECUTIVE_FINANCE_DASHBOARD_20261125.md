# Главный финансовый экран · 25.11.2026

Ответственный: технический исполнитель. Ветка: feature/marketplace-agents-staging.

## Изменение
Главный экран показывает четыре одинаковые карточки Ozon / WB / Яндекс / Итого и три итоговые строки: общие расходы, единый АУСН 8%, чистая прибыль. Подробная финансовая сводка и прежние карточки диагностики/источников перенесены под одну кнопку «Показать детали». Состояние раскрытия и узлы технических модулей сохраняются при обновлении.

Данные берутся из существующих защищённых API выбранного месяца. Убраны жёсткие октябрьские запасные расходы и ограничение чтения Ozon/WB одним месяцем. На смене месяца старые суммы заменяются состоянием загрузки, затем результатом текущего запроса; ответы устаревших запросов отсеиваются существующим serial gate. Отсутствующий регистр расходов остаётся неизвестным.

Финансовое ядро consolidated-pnl-core.mjs, API, D1, себестоимости и первичные документы не изменялись. Представление не выполняет повторный вычет расходов и налогов. Итог каналов остаётся частичным при неполном покрытии; доход Яндекса после услуг показан только в подробностях. Сценарии налога не попадают в итоговый АУСН и чистую прибыль. Предварительные показатели имеют статус «Оценка», отсутствующие — «Не закрыто».

## Проверки
- Реальный DOM-рендер на октябрьском проверенном примере: 4 карточки, Яндекс Н/Д, частичное покрытие 2/3, налог/чистая прибыль Н/Д; доход Яндекса находится в свёрнутых подробностях.
- Контракт полностью подтверждённого тестового убыточного P&L: налог и общие расходы вычитаются по одному разу; отрицательная прибыль и реальный ноль отображаются числами. Неполный налог блокирует окончательную прибыль.
- Раскрытие сохраняется при повторном рендере; технические DOM-узлы не теряются.
- Браузерные размеры 1440 / 800 / 390 / 320: 4 / 2 / 1 / 1 колонка без горизонтального переполнения в проверяемом компоненте. Дополнительно адаптация по ширине контейнера учитывает боковую навигацию.
- Синтаксис business-pnl.mjs проверен Node. Полная сборка локального репозитория не запускалась; используется штатная публикация Cloudflare Pages.

Новый интерфейс не закрывает прежние финансовые пробелы. Неполные налоговые и расходные источники сохраняют финальный итог неизвестным.
