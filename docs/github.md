# Размещение в GitHub

Выбранный репозиторий: agent. Репозиторий: https://github.com/cpsautoru-debug/agent. Видимость репозитория необходимо проверить в настройках GitHub.

1. Создать пустой private-репозиторий в своём GitHub без начального README.
2. В этой папке выполнить git init -b main, затем git add . и git commit -m 'Initialize agent workspace'.
3. Привязать адрес своего репозитория командой git remote add origin АДРЕС, затем git push -u origin main.
4. В GitHub Projects создать доску со статусами из workflow.md и представлениями по отделам. Создавать задачи через подготовленный шаблон Issue.
5. Для изменений кода использовать отдельные ветки и Pull Request. Workflow проверяет Instagram-сервис при push и pull_request.

Перед первой загрузкой проверить git status и список добавленных файлов. Секреты хранить вне репозитория; перед публикацией не переносить папку data или рабочий .env из старого проекта.

Для круглосуточного Instagram-агента потребуется отдельный сервер и настройка Meta; репозиторий этого не заменяет.
