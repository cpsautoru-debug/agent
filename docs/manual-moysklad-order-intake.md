# Ручные заказы Авито и дилеров через МойСклад

Статус: read-only показ в онлайн-офисе. Менеджер оформляет документ вручную в штатном интерфейсе МойСклад; офис читает документы и ничего не создаёт и не проводит.

## Как помечать заказ

В документе «Заказ покупателя» заполнять поле «Внешний код» по шаблону:

- Авито: `AS63:manual:avito:<уникальный номер>`
- дилер Руслан: `AS63:manual:dealer_ruslan:<уникальный номер>`
- дилер Ирина: `AS63:manual:dealer_irina:<уникальный номер>`

Пример уникального номера: `AV-20261125-001`. Номер после последнего двоеточия должен состоять из латинских букв, цифр, точки, дефиса или подчёркивания (1–64 символа). Он уникален внутри канала. Не помещать в него имя, телефон или адрес клиента.

В позициях документа выбирать точную номенклатуру МойСклад. Онлайн-офис связывает товар по UUID номенклатуры из позиции заказа, поэтому текстовое сходство не используется. Поле артикула/кода показывается как справочная информация.

## Отображение и границы

Кнопка в разделе «Заказы» читает заказы только по маркерам каналов, постранично по 100 записей. Каждый источник проверяется отдельно. Если общий размер выборки меняется, API возвращает ошибку или превышен лимит страниц, источник помечается неполным. Неполные данные в очередь не добавляются.

Список не содержит контактов покупателей. Повтор внешнего кода подсвечивается конфликтом. Отменой считается только документ со статусом типа `Unsuccessful`, если API возвращает этот тип; иначе статус не интерпретируется автоматически.

Заказ покупателя не подтверждает физическое наличие, готовность, пошив, передачу или отгрузку. Для таких этапов нужны отдельные подтверждения и будущая логика. До создания документов убедиться в договорной схеме (обычная продажа, отсрочка либо реализация), юридическом лице и складе.
