# MAX: отдельный обработчик Node.js

Этап: проверка подключения; приём заявок, webhook и запись в Google Таблицу пока не активны.

Обновление: добавлен тестовый HTTPS webhook /max/webhook. При запуске только на https://autosklad63-max.onrender.com сервис проверяет аккаунт бота и регистрирует bot_started/message_created с секретом, производным от токена (HMAC). На «Начать» и /start в личном диалоге отвечает собственным ID пользователя. Обычные сообщения и группы игнорируются; тексты не сохраняются. Защита от повторов этого технического ответа хранится в памяти и сбрасывается при перезапуске. Приём бизнес-заявок и запись в таблицу всё ещё выключены. /api/connection показывает webhookRegistered после успешной регистрации, без секретов и ID пользователей.

Render Web Service, бесплатный тип Free. Root Directory: apps/max-agent. Build Command: npm test. Start Command: npm start. Health Check Path: /health. Переменная MAX_BOT_TOKEN — только в защищённых Environment сервиса, вводит владелец. Значения секретов не хранить в репозитории.

GET /api/connection показывает только состояние подключения и публичный ник подтверждённого бота. Проверки объединяются и кэшируются на 30 секунд. GET /health не вызывает MAX. Входящие заявки на этом этапе не принимаются и не сохраняются.

TLS: официальный CA используется исключительно для HTTPS-запроса к platform-api2.max.ru. Проверка цепочки, имени сервера и срока сертификата включена. Системное хранилище не меняется, перенаправления с токеном не выполняются. Публичные сертификаты в certs/ получены с HTTPS-источника Госуслуг:
- https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt
- https://gu-st.ru/content/lending/russian_trusted_sub_ca_pem.crt

Render Free засыпает после 15 минут простоя и имеет непостоянный локальный диск. Для будущей очереди потребуется отдельное постоянное хранилище. Автоматические платные обновления не включать. План дальнейшего подключения: docs/max-sales-bot.md в корне репозитория.

Привязка владельца и группы: MAX_OWNER_ID и MAX_WORK_CHAT_ID вводятся в Environment Render, не в код. /chatid доступен владельцу в группе; /status — владельцу только в привязанной группе или личном диалоге. Ответы настройки приходят владельцу в личный диалог. Public health показывает только наличие привязки, не идентификаторы. Деловые заявки пока не принимаются, Google-доступ не настроен.
