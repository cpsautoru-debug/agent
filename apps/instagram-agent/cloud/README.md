# Бесплатный облачный приёмник Instagram

18.10.2026: Worker развёрнут из GitHub, база D1 и секреты настроены, приложение Meta опубликовано. Получение реального тестового сообщения и создание FAQ-черновика подтверждены через закрытый API. Отправка и облачная модель не подключены.

Ответственный: Instagram-агент, владелец доступа — Антон.
Вход: подписанные события Meta только аккаунта toxraa и подтверждённая база knowledge.json.
Результат: сообщения и FAQ-черновики в Cloudflare D1; защищённая панель `/panel` для просмотра, правок, передачи Антону и ручной отправки после её отдельного подключения.
Критерий готовности подключения: реальное тестовое входящее от владельца принято через HTTPS, сохранено один раз и прочитано через закрытый API. Локальные тесты не подтверждают подключение.

## Развёртывание

1. Использовать Workers Free и D1 Free, без перехода на платный план.
2. Создать D1 `autosklad63-instagram`, заменить `database_id` в wrangler.jsonc реальным ID.
3. Выполнить schema.sql в этой базе. Не загружать переписки в репозиторий.
4. Добавить секреты через Cloudflare Secrets: META_APP_SECRET (секрет Instagram-приложения), META_VERIFY_TOKEN (случайный токен проверки), ADMIN_TOKEN (случайный ключ не короче 32 символов). Не вводить их как обычные открытые переменные и не пересылать в чат.
5. Развернуть Worker этой папки Wrangler CLI либо сборкой из GitHub. В GitHub подключать только репозиторий agent, не все репозитории.
6. Проверить /health, callback /webhook и подписку Meta. Сам /health не проверяет готовность D1 и доступ к Meta.
7. После успешной проверки callback включить нужные события Meta с согласия владельца. Проверить реальное входящее, повтор того же события и неверную подпись.

Панель: https://autosklad63-instagram.cpsautoru.workers.dev/panel . Вводится ADMIN_TOKEN; он остаётся только в памяти вкладки и не включается в ссылки, localStorage или исходники. Выход удаляет список из интерфейса. Сообщения выводятся как текст, без HTML клиента. API доступен только с Bearer-ключом, без CORS.

`GET /api/drafts` возвращает последние 100 событий за 30 дней. Правки и действия требуют актуальной ревизии. Кнопка отправки включает отдельное подтверждение текста. Для ручной отправки владелец должен сохранить INSTAGRAM_ACCESS_TOKEN как Secret, META_API_VERSION=v26.0 и ALLOW_SEND=true. Сама установка ADMIN_TOKEN отправку не включает. Автоответов нет. Лимит — 30 попыток в сутки UTC. Одновременная повторная отправка, старые черновики и новые ручные ответы блокируются условным UPDATE в D1. Сбой после начала отправки остаётся в состоянии sending или uncertain; автоматического повтора нет.

D1 хранит переписку 30 дней; ежедневная очистка выполняется планировщиком. Секреты и тексты не пишутся в консоль. При ошибке сохранения возвращается 503, чтобы Meta могла повторить доставку; ID события уникален, повторные доставки не перезаписывают исходную запись. Лимиты бесплатного тарифа не являются гарантией доступности. Облачная LLM здесь не подключена: используются FAQ и передача человеку.
